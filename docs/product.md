# 团团 Tuantuan 产品说明（MVP）

## 用户任务

1. 用 Prompt + 工具 + Skills 快速组合出不同角色的 Agent，并选择 Auto 或固定模型。
2. 在群聊中 @ Agent 让它们回答（不 @ 时自动选一个，@所有人 时每个都回答），Agent 之间可以用 handoff 工具交接任务。
4. 和绑定了 Agent 的桌面机器人语音对话。
3. 了解每条回复用了哪个模型、为什么、是否发生回退，以及调用了哪些工具。

## 业务规则（已确认）

- Agent 名称唯一（不区分大小写），不能包含空白、`@`、反引号，也不能是 `所有人` / `all` / `everyone`；名称即 @ 的目标。
- 群聊（2026-10-14 Andy 确认，取代原先"没有 @ 时无人回复"）：
  1. @ 了具体 Agent → 只有这些房间成员回复。
  2. 没有 @ → 按话题选**一个**成员回复。选择链：决策模型（成员名 + Prompt 摘要作为选项）→ LLM 分类模型 → 关键词规则 → 第一个成员。选择人、置信度和理由记录在路由记录里，消息下方显示「按话题选中」。
  3. `@所有人`（或 `@all`、`@everyone`）→ 每个成员按成员顺序各回复一次；这一轮里已经回复过的 Agent 不会因为别人交接而再回复，仍受跳数上限约束。只有人类消息里的 @所有人 生效。
  4. Agent 之间只能通过内置的 `handoff(agent, task)` 工具交接（见下一条）。
  5. 回复链进行中用户又发了消息 → 立即中止正在生成的回复（保留已生成部分，标记「被新消息打断」），丢弃尚未执行的交接（系统消息列出），然后处理新消息。
- 私聊：每条消息都由该 Agent 回复；新消息按顺序排队，不会打断。
- Agent 回复正文里的 `@名字` 只是显示用的提及，**永远不会触发**对方。群聊里的 Agent 有一个内置工具 `handoff(agent, task)`：只有调用它才会让对方在本条回复结束后接手，而且对方会看到 task。不能交接给自己；本条消息里已在排队的 Agent 不会被重复触发。界面在回复里显示「交接给 X」卡片（附 task），接手方回复下方显示「接 X 的交接」。系统提示要求只在用户这次的请求确实需要对方现在动手时才交接，不要用来介绍或推荐别人。
- 每条人类消息引发的 Agent 交接最多 `maxAgentHops` 次（默认 5），超出时停止并在会话中提示未执行的触发。
- 同一会话同时只处理一条人类消息的回复链；群聊中新消息会打断当前链（见上），私聊中排队；不同会话互不影响。
- 取消：停止当前回复（保留已生成内容，标记「已取消」），并丢弃排队中的消息（会话中提示数量）。
- 失败如实展示：模型全部失败、工具失败、达到工具迭代上限、服务重启中断都会在对应消息上显示原因。

## 关键状态

消息：`回复中` → `完成` / `失败` / `已取消`；服务重启时未完成的消息变为 `已中断`。
会话：空闲 / Agent 正在回复（可取消）/ N 条排队中。

## 界面

- 视觉：现代、俏皮但克制，和圆滚滚的 Bot 吉祥物相配。中性底色（浅色 `#ffffff` / `#f5f5f3`，深色 `#161618` / `#111113`），石墨色文字与主按钮；品牌色番茄珊瑚红（Logo `#f2553c`，交互 `#e8462b`，深色 `#ff6a4d`）只用于发送、按住说话、选中图标、@ 提及和交接这类关键位置；色彩主要来自 Agent 头像（13 种鲜亮颜色）。字体 Plus Jakarta Sans Variable（自托管拉丁）+ 苹方 / 系统中文黑体，标题与正文同一家族、靠字重区分。表面圆角 10–16px（不做全胶囊），1px 细线 + 轻柔分层阴影，按钮按下有轻微回弹，减少动态效果时关闭。避免：默认靛蓝、满屏渐变、毛玻璃、emoji 图标、卡片网格。界面不写操作说明，解释都放在文档里。
- 动效：切换页面/会话时主区域淡出淡入并轻微位移（支持 View Transitions 的浏览器用它，其他浏览器退回 CSS），弹层、@ 列表、Cmd+K、头像选择器从触发位置缩放淡入，右侧面板滑入滑出（窄屏为底部抽屉），新消息上浮淡入；时长 120/180/220ms，统一缓动 token；关闭时也有退场动画；开启「减少动态效果」时全部关闭。
- 对齐：所有列的标题栏同在一条 56px 线上（导航 Logo、列表标题、主区域标题、详情标题），标题栏不透明并带底部细线，内容在其下方滚动、不重叠；列表、消息列、输入框、详情键值列各自共享左边缘。e2e 用 `getBoundingClientRect` 断言这些对齐。
- 桌面三栏：导航栏（会话 / Agents / 机器人 / 搜索 / 显示名 / 连接状态）+ 列表 + 主区域，详情面板可展开；≤1180px 时详情变为浮层，手机端列表和主区域分屏切换，详情变为底部抽屉。浅色/深色跟随系统，尊重减少动效设置。
- 会话列表按群聊 / 私聊 / 桌面机器人分组；Cmd/Ctrl+K 打开切换器。
- Agent 头像：13 种手绘 SVG Bot 轮廓 + 13 种颜色（默认按 Agent id 确定性生成，存于 `avatar_shape` / `color`）；在编辑页点击头像打开选择器（方向键切换、Esc 关闭、可重置）。人类头像为描边圆。头像有表情：平静 / 开心 / 思考 / 说话 / 惊讶 / 难过 / 休眠。只有正在进行的回复和成员列表会动（眨眼、呼吸、张望；等首字时思考摇摆，流式输出时说话，开始回复时跳一下，结束时短暂微笑，失败时摇一次）；20px 以下只眨眼，减少动态效果时全部静止，离屏和标签页隐藏时暂停。预览页：`#/dev/avatars`。
- Agent 编辑：顶部 56px 标题栏（小头像 + 名称 + 「Auto 路由 · N 个工具 · N 个 Skills」一行，右侧「私聊」）；分区（基本信息、系统 Prompt、模型、工具、Skills、危险操作）、可搜索的勾选列表；底部不透明保存条，状态文字和按钮与内容列对齐。
- 头像表情与真实状态对应：等待首字 = 思考，流式输出 = 说话，失败 = 难过，被取消/中断 = 惊讶，所在机器人设备离线 = 休眠，其余 = 平静。
- 聊天：同一发送者 5 分钟内的消息合并；Markdown 与代码高亮；@ 显示为标签并支持自动补全（↑↓ 选择，Enter/Tab 确认；Enter 发送，Shift+Enter 换行）；工具调用默认折叠；每条 Agent 回复下方只有一行弱化的来源信息（「按话题选中」/「接 X 的交接」· 模型 · 是否回退，悬停时加深），点击后在详情面板查看路由、分类器与工具；交接显示为带左侧强调线的卡片；停止按钮与排队数。
- 输入框：在群聊中输入时，底部实时显示这条消息将由谁回复（被 @ 的 Agent / 所有人 / 按话题自动选一位），回复进行中提示「发送会打断当前回复」。
- 会话信息面板（默认收起）：成员头像、Auto/固定模型、工具与 Skills 数、本会话回复数（点击进入编辑）；群聊「谁会回复」规则摘要；本会话模型使用分布与按话题选中 / 交接 / 回退 / 失败计数。
- 桌面机器人（`#/robot`）：选择绑定的 Agent，动画脸部显示 待机/聆听/思考/说话/开心/难过或出错/惊讶；按住说话或免提（Web Speech），zh-CN 朗读，文字输入兜底；可以打断（barge-in）；Agent 通过 `robot_express` / `robot_action` 控制表情和动作（点头、摇头、歪头、挥手、环顾、跳舞）。对话保存为聊天列表中的「桌面机器人 · Agent」会话；网页机器人使用固定设备 id `web-robot`，重复打开不会新增会话（旧版本留下的空会话由数据库迁移清理）。协议见 [device-protocol.md](device-protocol.md)。

## 验收条件

- 不配置任何 Key，`bun dev` 后可完成：建 Agent → 建群 → @A → A 用 handoff 交接给 B → B 回复，且能看到路由信息。
- A、B 互相交接时在第 `maxAgentHops` 次后停止并出现提示。
- A 的回复正文写「可以让 @B 接手」但没有调用 handoff 时，B 不回复。
- 勾选工具后，工具调用及失败在 UI 中可见。
- 取消后正在回复的消息显示「已取消」，排队消息不再触发。

## 待验证假设

## 品牌

- 名称：**团团 Tuantuan**，意思是"团聚、圆滚滚"，指一群 Agent 围在一起协作。
- Logo：两个圆形 Bot 依偎在一起（石墨色在前、珊瑚红在后），沿用头像的斜眼睛造型；导航栏里的 Logo 会眨眼，悬停时两个 Bot 互相看一眼，开启"减少动态效果"时静止。
- 资源：`web/public/favicon.svg`（随系统深浅色切换）、`favicon-32.png`、`apple-touch-icon.png`，字标在 `docs/brand/`。
- 仓库：`bosshanz/tuantuan`（原 `agent-hub`，旧地址自动跳转）。
- 兼容：`AGENT_HUB_*` 环境变量、默认数据库文件名和 localStorage 键保持不变。
