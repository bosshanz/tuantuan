# 团团 Tuantuan 产品说明（MVP）

## 用户任务

1. 用编码 Harness（Claude Code / Codex / Grok Build / OpenCode / Pi / MiniMax Code，或 ACP Registry 里的其他 Agent）组合出不同角色的 Agent：Harness、身份文档、Skills、服务商、MCP 服务器、环境变量、权限策略。
2. 按项目组织会话：单 Agent 会话直接对话；多 Agent 会话不 @ 时由群主（主 Agent）负责分工、跟进、接收结果和最终汇总，明确 @ 成员仍然直接对话，@所有人 时每个都回答。
3. 完整看到 Harness 的能力：流式回复、思考、工具调用（diff / 终端）、计划、权限请求、配置项、斜杠命令、图片、会话历史、用量。

## 业务规则

- 模型列表以 Harness 实际返回的选项为准。登录成功、额度可查询与某个模型可选是独立状态；本机 Antigravity ACP 1.4.0 对团团只返回 Gemini，不据此声称 Antigravity 所有客户端都不支持 Opus。
- 团团不做模型路由；模型、原生登录由 Harness 管理。例外：「自定义 API（BYOK）」轻量 harness 只做对话。服务商按进程环境 / ACP 传给 Harness，不写用户文件。团团保存的服务商、BYOK 与 Harness `env_var` Key 当前为 SQLite 明文，专用接口只给前端掩码；普通 Agent 环境变量是可读写配置。系统钥匙串仍是未完成的计划。
- 本机边界：API 默认监听 `127.0.0.1`，HTTP（含 MCP）和 WebSocket 升级都检查本机 Host、浏览器 Origin、跨站请求标记；兼容本机 Vite 代理及不带 Origin 的原生客户端。`TUANTUAN_HOST` 只改变监听地址，不提供远程鉴权或放宽请求检查。
- 首次启动：一页三步引导（选 Harness 并可一键安装 → 需要时登录 → 给第一个 Agent 起名，创建后在「草稿」打开会话），随时可跳过，只出现一次。
- Harness 来源：Harness 页填的绝对路径 → 用户自己装的（登录 shell 的 PATH）→ 团团内置（源码运行或 `TUANTUAN_BUNDLE_ADAPTERS=1` 的桌面包）→ 团团从 ACP Registry 安装的。一键安装只在用户点按钮后执行，不用 sudo、不装全局。
- Agent 名称唯一（不区分大小写），不能包含空白、`@`、反引号，也不能是 `所有人` / `all` / `everyone`；名称即 @ 的目标。
- Harness 进程按会话 + Agent + 工作目录隔离，每对会话 / Agent 对应一个 ACP session，重启后按能力恢复（resume / load）。
- 团团 ACP `fs/*` 按真实路径限制在会话工作目录内；当前 Agent 选中的 Skill 目录及附属文件额外允许只读，每轮替换，写入范围不变；拒绝符号链接逃逸。新文件按最近的现存父目录校验。ACP 终端只检查启动 `cwd`，命令本身仍以用户权限运行，不能保证其文件访问留在目录内；Harness 自带工具由自身权限 / 沙箱控制。旧说明将文件与终端都描述为完全受目录限制，范围过宽；当前不是操作系统沙箱，也不隔离校验后发生的并发文件系统变化。
- 权限请求由 Harness 发起，选项来自 Harness；团团按 Agent 策略展示弹窗或自动选择允许选项。授权 POST 成功后关闭；失败保留原弹窗、显示错误并可重试，提交中禁止重复操作；404 表示请求已失效，关闭弹窗。
- 提问卡片由 Harness 通过 ACP form elicitation 发起：团团只声明表单模式，不声明 URL 模式（URL 流程会离开团团、无法跟踪）。字段支持字符串（含枚举 / 选项列表）、数字、整数、布尔和多选数组，带必填、长度、格式、数值范围与选项校验；当前版本不认识的字段类型只读显示并阻止提交，只能取消。提交成功后关闭；校验失败或服务端提交失败保留卡片、显示错误并可重试，提交中禁止重复提交。用户关闭、停止任务、进程退出或离开会话都会以 cancel 回应，Harness 不会一直等待；提问随房间快照恢复，刷新后仍在。OpenCode 会话默认启用其原生提问工具（`OPENCODE_ENABLE_QUESTION_TOOL=1`，显式配置优先）。
- 身份文档保存在团团，不写入用户仓库：Claude 用 `_meta.systemPrompt.append`，Grok 用 `_meta.rules`，Codex 用进程环境 `CODEX_CONFIG.developer_instructions`，OpenCode / Pi 等其他 Harness 附加在新会话首条普通消息前。Claude Code、OpenCode、Pi、Codex 的基础提示词由实际启动的原生引擎提供，团团不维护固定副本；Codex 目录外模型的通用指令也从当前 CLI 读取。用户原生提示词配置、已有会话的提示词恢复与更新规则仍由 Harness 管理。
- 项目：名称 + 目录（新建或选已有文件夹，根目录默认 `~/Tuantuan`）；未选项目时进「草稿」。项目下的会话共用目录；改目录会重置这些会话的 Harness 上下文。
- 多 Agent 会话：
  1. @ 了具体 Agent → 直接交给这些成员，包括明确 @ 群主；不自动安排群主跟进或汇总。
  2. 没有 @ → **群主（主 Agent）** 负责本轮结果（建会话时选，可在详情面板修改）。简单任务可以自己完成；需要协作时按成员能力分工，本批所有成员结束后自动收到结果，决定补充分工或最终汇总。群主在消息发送时确定；更换群主只影响新请求，进行中的请求由原负责人收尾。
  3. `@所有人`（或 `@all`、`@everyone`）→ 每个成员各回复一次；不同 Agent 并行，同一会话内同一 Agent 按入队顺序执行。
  4. 群聊转述从截至本次请求的最近 30 条记录取候选；交接另查本轮已完成的回复，不被其他请求的新消息挤出候选。候选中取该 Agent 上次成功发言之后的内容，普通正文整体约 8000 字符、单条长正文约 2000 字符，保留首尾并标明省略、消息 ID，优先较新消息。`read_context` 提供历史目录及完整原文分页。本次原始请求全文、引用快照和结构化任务笔记独立附上，不受转述预算裁剪；排队期间的新消息不能取代本次任务。
  5. Agent 之间只能通过团团注入的 `tuantuan` MCP 服务器上的 `handoff(agent, task, context?)` 交接：只能交给会话里的其他成员，不能交给自己；`task` 去除首尾空白后完整保留，最多 16,000 字符，超限拒绝且不占预算。本条消息里已在执行、排队或等待交接的目标不重复触发；`@所有人` 这一轮已触发过的不再触发；每条人类消息最多 5 次交接，超出时停止分工并提示；回复失败或被取消时它发起的交接作废。正文里的 @ 永远不触发。
  6. 群主统筹的请求中，只有本轮群主能分工；成员完成分配的任务后，结果自动回流，无需再调用交接。每批结果包含任务摘录、完成 / 失败 / 取消状态、消息 id、回复内容及完整成功笔记；任务说明最多 2000 字符首尾摘录并附原文读取位置，正文超过 6000 字符时明确省略，可分别用 `read_context` / `read_result` 分页追读。成员笔记作为待核对资料，不自动变成群主的决定。群主可再次安排已完成或失败的成员，仍共享 5 次分工预算；自动回流不占预算，最后一次分工结束后仍会汇总。`list_members` 提供成员身份说明，辅助按能力分工。
  7. 新消息不自动打断。停止按任务定位，只取消该任务及其后续工作；独立消息和并行兄弟任务继续执行。来源已完成、成员尚在运行时，仍可从「统筹中」或「交接中」来源任务停止后续工作。单独取消成员会把取消状态回报群主，该成员在本轮不再自动重派；取消群主根任务则停止整轮及后续汇总。移除群主或关闭会话也不会重新唤起它。
- 交接笔记：Agent 用 `save_context` 显式记录任务目标、已确认关键决策、未完成 / 待核实事项，三字段完整替换，空数组可清空。完整 JSON 最多 4000 字符，单项最多 2000 字符，数组各最多 20 项；非法提交保留原值。仅本条回复成功结束才随消息持久化，失败、取消、输出未完成或中断不提交。`handoff.context` 显式提供时仅作用于该目标，省略时复制当前任务收到 / 暂存的笔记；后续保存不改写已接受快照。群主跟进继承上一批自身笔记，不同用户请求不自动混用。笔记完整传递且刷新可回看，不依赖额外模型摘要调用。
- 结论卡：置顶只读卡片，从最近一条成功保存的任务笔记派生，只接受根任务或群主跟进回复（成员交接回复的笔记留在各自消息里，不合并成群主决定）。新一轮没有新笔记时继续显示上一张；默认收成一行（当前目标 + 决策与未完成的数量），展开显示三栏；点击可跳到来源消息。没有符合条件的笔记时不显示。结论不新增数据表、不做自动摘要，刷新和重启后按消息重新派生。
- 原文追读：活动成员可通过 `read_context` 获取历史消息目录（每页 20 条）和正文 / 交接说明（每页 6000 字符），并读取成功笔记。只允许同房间截至原始请求的已结束消息及本请求后续结果；后来独立请求、生成中内容、已取消或过期任务不可读取。普通转述候选之外的早期记录仍可按目录追读；来源的完整工具历史和私有会话状态不在交接范围内。
- 群主职责按每一轮的实际路由注入提示，长期身份文档不固定“你是群主”。结果收集、自动续轮、预算和取消边界由团团调度器保证；模型根据提示负责分工质量、复核与汇总内容。
- 单 Agent 会话：每条消息都由该 Agent 回复；新消息排队；不注入 `tuantuan` 工具。
- MCP 配置：增删绑定、删除服务器或修改已选插件的 MCP 配置，在下一次空闲会话挂载时生效；正在执行的任务和权限请求继续使用原会话。支持 resume / load 的 Harness 保留历史，不支持时新建会话；初始化期间变更配置会拒绝旧结果并提示重试。
- 原生上下文：每个房间 / Agent 独立复用 Harness 会话，历史与压缩由原生引擎管理；通过 Claude Code、OpenCode、Pi、Codex 使用自定义 API 也遵循此规则。团团未实现统一语义摘要、共享长期记忆或专用压缩控制面板。恢复按能力走 resume / load，失败或超过 45 秒会新建；不支持恢复或映射已重置也新建，不自动重放全部团团聊天记录。
- 直接 BYOK 上下文：仅 Harness 选择「自定义 API」时，按房间与 Agent 保存最多 20 个完整成功轮，重启继续相同上下文。每次请求（含工具续请求）的完整序列化内容最多 65,536 字符，按完整旧轮淘汰，不生成语义摘要；当前任务或工具链自身超限明确报错，不截断系统提示或当前任务。失败、取消及重置后的迟到回复不覆盖上一成功上下文。新会话、成员移除、项目目录 / 归属重置会持久化清空；已有聊天记录仍可回看。这是字符上限，不是精确 token 窗口。
- Skills：自动发现用户级、插件和项目里的 Skills，按 Agent 勾选；原生全局 / 项目技能显示「原生可用」并保留来源，不能在这里假装停用。团团勾选的技能每轮以按需路径索引提供给当前 Agent，不再写入共享项目。取消勾选会撤销下一轮索引与额外只读权限；已有历史内容不会追溯删除。不能确认归属的旧项目链接保留，按原生来源展示。
- API Key：`env_var` 登录方式的 Key 可在 Harness 页、首次引导、会话的「需要 API Key」提示里填写；Registry 普通登录方式的错误明确指出缺少的 Key 变量名时，也提供对应输入框。服务端保存、打码显示、只注入该 Harness 的进程（Agent 环境变量优先），保存后重新握手。终端登录用团团安装的绝对命令在终端打开，并可复制。
- 登录：Registry 安装完成自动握手，已有安装可手动握手；Harness 声明了 agent 类型的登录方式时可一键调用 ACP `authenticate`，环境变量类显示输入框，终端类提供打开和复制命令。等待期间防止重复登录和冲突操作，失败保留方法与错误供重试，建会话失败的原因不丢弃；不能确认登录状态时显示未知，已可用时不强迫重登。第三方服务商支持 Claude Code、OpenCode、Pi、Codex 和自定义 API，其他 Registry Agent 不推断未声明的兼容性。
- 服务商：Claude Code 要求 Anthropic 地址；OpenCode / Pi 要求任一兼容地址和主模型；Codex 要求实际支持 Responses 的 OpenAI 地址。双地址时 OpenCode / Pi 优先 OpenAI，接口格式选择不转换协议。编辑需保留已绑定 Agent 的必需配置；切换清除旧默认模型，删除回到本机配置。配置只作用于对应进程，不改 Harness 用户配置或隐藏 Pi 原生资源。
- 切换到 Harness 的历史会话时 `session/load`，回放中团团没有的轮次（按用户消息文本去重）只读显示在顶部。
- 取消：初始化期间停止等待，不再向该已取消任务发送 prompt；运行期间先发 `session/cancel`，保留已生成内容并标记「已取消」。默认 4 秒内 Harness 仍未结束则回收该会话 / Agent 的进程组，不影响其他会话；同一 Agent 的下一项独立任务等待取消完成再运行。回复期间切换 ACP 历史会话返回明确错误，避免覆盖活动任务。Agent 设置、项目目录或会话选择变更会使旧的初始化结果失效。删除会话、变更项目目录会明确取消受影响会话的全部任务；移除 Agent 会取消它的任务及依赖交接。
- 重试中断请求：服务重启后未完成的 Agent 回复标记「已中断」，提供「重试此请求」。它把原用户消息的正文与图片作为一条**新请求**重新发送，并引用原消息说明来源；按新消息重新路由（原 @ 目标不变，群聊无 @ 仍交给群主，单 Agent 会话仍由该 Agent 回复），不恢复旧任务、不沿用旧排队或交接。只有被中断的 Agent 请求显示该操作；普通失败、取消和权限错误保留原有按钮与语义。
- 安装：Registry 的 id 与版本段经过路径校验；二进制 / npx 使用独立随机暂存目录，成功后发布，失败或取消清理；uvx 因固定 venv 路径直接安装到目标版本目录，失败清理。取消或超时会终止安装命令进程组。
- 失败如实展示：Harness 未安装、未登录（Authentication required）、进程退出（附 stderr 末尾）、安装失败（校验和不匹配等）都显示在对应位置。

## 关键状态

消息：`回复中` → `完成` / `失败` / `已取消`；服务重启时未完成的消息变为 `已中断`。
会话：空闲，或同时包含回复中、排队中、停止中、交接中与统筹中的任务。群主等待成员时显示「统筹中」，自动收到结果后显示「跟进中」。每项显示 Agent 和请求摘要，按任务停止；状态以服务端为准。浏览器刷新 / 重连恢复队列投影，服务重启后队列不重放，已开始但未完成的消息标记为已中断。
前端快照：只接受当前会话最新一次加载；期间收到的运行状态、会话、权限与提问增删事件按顺序重放到快照，消息按 id 合并；结论卡取服务端快照、已加载消息与实时事件中最新的成功笔记。旧快照不能移除停止按钮、丢失权限或提问弹窗、恢复已解决的请求，或把结论卡退回旧笔记。
侧栏预览：独立接收所有会话的最后消息更新，不依赖通知开关或当前打开的房间。回复期间显示「正在回复…」，完成、失败或取消后更新摘要；重连刷新列表，加载期间收到的新摘要不能被旧快照覆盖。

## 界面

- 界面语言：在「设置 → 个人资料 → 界面语言」选择简体中文（`zh-CN`）、繁体中文（`zh-TW`）、英语（`en`）、日语（`ja`），默认简体中文。自动保存成功后立即生效；个人资料按顺序保存连续修改，失败保留草稿并可重试。同一本机服务的其他窗口接收 `profile.updated` 同步，重连后重新读取。服务端 `profile.language` 为权威值，`localStorage` 只提供启动缓存。
- 模型能力与思考等级：models.dev 目录与 Pi AI 协议兼容规则用于 Claude Code / OpenCode / Pi / Codex；官方接口地址优先于预设识别，未知模型不猜测，同模型在不同服务商上的等级可不同。可为模型别名关联能力来源，不改变请求 ID。新会话优先会话设置、Agent 默认和已识别的明确原生配置，再用实际 ACP 支持的团团推荐值；恢复或切模型时保留并重放明确选择，暂不支持时保留意图以便切回恢复。目录同步失败保留旧值，运行中的进程不受更新打断。各 Harness 的关闭、目录和原生配置边界见 [服务商](providers.md#模型能力目录与思考等级)。
- Harness 升级：能力选项跟随实际使用的 ACP / CLI，包含同路径覆盖更新及适配器配套引擎更新。空闲接入时刷新进程和选项缓存，活动任务不中断，用户明确选择保留。新增等级以目录事实及原生能力为准，不由团团固定名单封顶；无法识别的新协议不猜测配置。
- 翻译范围：应用的页面、按钮、帮助、错误提示、输入提示、无障碍标签，以及桌面菜单和系统通知的应用文案。聊天与 Agent 正文、用户填写的名称、路径和模型 ID 保持原值；未知第三方文案和错误保留原文。界面语言不写入 Agent 指令，不改变模型回复语言。
- 视觉：现代、俏皮但克制，和圆滚滚的 Bot 吉祥物相配。中性底色（浅色 `#ffffff` / `#f5f5f3`，深色 `#161618` / `#111113`），石墨色文字与主按钮；品牌色番茄珊瑚红（Logo `#f2553c`，交互 `#e8462b`，深色 `#ff6a4d`）只用于发送、按住说话、选中图标、@ 提及和交接这类关键位置；色彩主要来自 Agent 头像（13 种鲜亮颜色）。字体 Plus Jakarta Sans Variable（自托管拉丁）+ 苹方 / 系统中文黑体，标题与正文同一家族、靠字重区分。表面圆角 10–16px（不做全胶囊），1px 细线 + 轻柔分层阴影，按钮按下有轻微回弹，减少动态效果时关闭。避免：默认靛蓝、满屏渐变、毛玻璃、emoji 图标、卡片网格。界面不写操作说明，解释都放在文档里。
- 动效：切换页面/会话时主区域淡出淡入并轻微位移（支持 View Transitions 的浏览器用它，其他浏览器退回 CSS），弹层、@ 列表、Cmd+K、头像选择器从触发位置缩放淡入，右侧面板滑入滑出（窄屏为底部抽屉），新消息上浮淡入；时长 120/180/220ms，统一缓动 token；关闭时也有退场动画；开启「减少动态效果」时全部关闭。
- 布局：单侧栏（会话行 + 可折叠项目分组，底部设置），主区悬浮居中标题、左右气泡（Agent 浅色在左、名字在上；我深色在右）、圆角悬浮输入框，右侧详情面板（详情 / 资料库 / 成员，可添加成员）。
- 对齐：侧栏顶行、悬浮标题与详情标题同在一条 56px 线上；未分组会话与项目标题共享左边缘，项目内会话缩进一级，数量右对齐；Agent 名字、元信息与气泡内文字对齐；输入框在消息列中居中。e2e 用 `getBoundingClientRect` 断言这些对齐。
- 桌面三栏：导航栏（会话 / Agents / Harness / 服务商 / 搜索 / 显示名 / 连接状态）+ 列表 + 主区域，详情面板可展开；≤1180px 时详情变为浮层，手机端列表和主区域分屏切换，详情变为底部抽屉。浅色/深色跟随系统，尊重减少动效设置。
- 会话列表按项目分组；还没有 Agent 时只显示「创建 Agent」卡片。Cmd/Ctrl+K 打开切换器。
- Agent 头像：11 种可选手绘 SVG Bot 轮廓（含小猫、小狗、兔子、熊猫、山羊、牛） + 13 种颜色（默认按 Agent id 确定性生成，存于 `avatar_shape` / `color`）；在编辑页点击头像打开选择器（方向键切换、Esc 关闭、可重置）。方块、星芒、豆子、水滴、胶囊、三角、菱形、六边形退出新选择与默认分配，已保存的这些形象继续兼容显示和编辑保存。人类头像为描边圆。头像有表情：平静 / 开心 / 思考 / 说话 / 惊讶 / 难过 / 休眠。只有正在进行的回复和成员列表会动（眨眼、呼吸、张望；等首字时思考摇摆，流式输出时说话，开始回复时跳一下，结束时短暂微笑，失败时摇一次）；20px 以下只眨眼，减少动态效果时全部静止，离屏和标签页隐藏时暂停。预览页：`#/dev/avatars`。
- Agent 编辑：顶部 56px 标题栏（小头像 + 名称 + Harness 名称，右侧「对话」）；分区（基本信息、Harness、服务商与默认设置、权限策略、身份文档、Skills、MCP 服务器、环境变量、危险操作）；底部不透明保存条。
- 首次引导（`#/setup`）见业务规则。Harness 管理（`#/harness`）：常用 6 个 Harness 显示是否安装、来源、版本、一键安装 / 更新 / 卸载、登录方式、绝对路径覆盖和握手测试；「更多 Agent」列出 ACP Registry 全部 Agent（图标、简介、版本、协议、平台），可搜索、安装、握手。
- 头像表情与真实状态对应：等待首字 = 思考，流式输出 = 说话，失败 = 难过，被取消/中断 = 惊讶，其余 = 平静。
- 聊天：同一发送者 5 分钟内的消息合并；Markdown 与代码高亮；@ 显示为标签并支持自动补全（↑↓ 选择，Enter/Tab 确认；Enter 发送，Shift+Enter 换行）；**精简视图默认开启**——Agent 回复保留它写下的正文（超长先露开头一段，其余「展开全文」），思考、每条工具与计划收成一行过程摘要（如「12 个工具 · 3 段思考 · 计划 2/5」），点击就地展开完整过程，工具失败时摘要带失败标记并自动展开；进行中的回复不再逐行追加，只显示已到达正文加一行实时状态（当前工具名、无工具时「正在处理」，附已运行时长）。权限弹窗、提问卡片、失败、中断后的「重试此请求」和回复中的图片始终留在主界面。聊天顶部「精简视图」开关（存本机）可关闭，关闭后回到完整时间线：思考、工具逐行内联显示（工具行本身仍默认折叠）。每条 Agent 回复下方一行弱化的来源信息（如「接 X 的交接」）；交接显示为带左侧强调线的卡片，可展开目标、决策、未完成事项，长说明可滚动阅读完整内容；成功回复的任务笔记同样可展开，旧消息无笔记时保持兼容；停止按钮与排队数。
- 消息操作：操作栏位于气泡外，桌面悬停 / 键盘聚焦时显示，打开菜单时保持可见；触屏直接可见，窄窗口放到气泡下方。更多菜单支持复制正文、复制团团消息 ID（非 Harness 请求 ID），Agent 消息可查看详情；复制不包含思考、工具记录和引用原文，空正文不可复制，失败显示原因并可重试，等待期间不重复提交。被中断的 Agent 请求在正文下方显示「重试此请求」（其他语言使用同义说法，明确是重新发起而不是继续原流程），失败时就地显示原因并可再次点击。
- 群聊引用回复：已完成的用户 / Agent 消息在操作栏提供引用图标；输入框显示作者和摘录，可取消。发送失败保留草稿与引用，成功后清除；消息内的引用刷新后仍可见。服务端只接受同群消息 id，生成最多 400 字符的引用快照，并把摘录独立放进本轮 Agent 上下文；引用不自动 @ 作者，原文里的 @ 不触发成员，响应者继续由新消息里的显式 @ 或主 Agent 规则决定。
- 输入框：多 Agent 会话中实时显示这条消息将由谁回复（被 @ 的 Agent / 所有人 / 主 Agent）。输入框上方以轻量状态条分别显示参与协作的 Agent 头像、名字、当前状态与各自排队数量；同一 Agent 合并显示，最多直接显示 3 位，其余显示人数并可展开查看，窄窗口自然换行。正在处理者优先，等待成员结果、等待交接和排队者仍在摘要中。准备、回复、跟进、停止和等待分别表达，动态圆点只表示正在处理，不表示完成进度；减少动态效果时静止。点击或用键盘展开可查看每项 Agent 的头像、请求摘要与状态并逐项停止，任务全部结束后状态条消失。展开 / 收起以 220 / 180ms 高度过渡，连续点击从当前高度反向，文字保持原尺寸；收起立即禁止访问隐藏的操作，保留列表滚动位置。聊天原本跟随底部时继续跟随，阅读历史时保持位置；减少动态效果时直接切换终态。只有唯一可停止任务时提供状态条与输入框快捷停止；多任务时逐项选择，发送继续可用。停止失败保留任务和可重试入口，折叠时错误也直接可见，提交中防重复。单 Agent 的常用设置入口为模型、权限、推理；其他选项放进「更多设置」，窄窗口继续收起次要入口；群聊保留「各自设置」。
- 会话信息面板（默认收起）：成员与 Harness；项目目录与主 Agent；每个 Agent 的 ACP 会话（历史列表、切换、新会话）、配置项与用量。
- 项目终端：从会话右上角或 Ctrl+` 打开，停靠在会话下方；每个项目可用标签页多开独立交互式登录 shell，初始目录为项目文件夹。新增、切换、关闭单页互不影响；顶部可拖动或用方向键调整高度。收起、切换会话与浏览器刷新保留全部运行进程，重新打开恢复有限输出；最后一个终端结束后收起面板。项目改目录、删除或服务退出时回收该项目全部终端。终端以本机用户权限运行，主动脱离任务遵循 shell 语义；当前支持 macOS / Linux，服务重启后不恢复进程。
- 终端动效：面板连续展开 / 收起，快速反向操作从当前高度继续，文字保持原尺寸；首次加载和结束终端沿用同一布局过渡。拖动与键盘调整高度立即响应。收起后不再接收输入，焦点原本在终端内时回到工具栏；后台重连不抢焦点。减少动态效果时直接切换终态。聊天原本跟随底部时继续跟随，阅读历史消息时保持位置。
- Grok 额度：刷新时通过它自己的 ACP billing 扩展只读查询周期额度、套餐和预付余额；本机会话 token / 花费仍单独显示。缺失或查询失败不记为零。额度区移除 OpenCode 的不支持占位卡，其他 OpenCode 功能保留。
- Registry 额度：已安装或已绑定 Agent 的 Antigravity / ZCode 显示卡片，登录或握手成功后同步，也可单独刷新。Antigravity 只调用已声明且原生拦截的 `/usage`；ZCode 只调用 `account/usage_stats`。来源、查询时间与错误可见，缺失不记为零；缓存可恢复，打开页面不触发登录。ZCode 0.70.0 不支持团队套餐的认证与额度查询，个人渠道返回值不能代表团队余额，也不能仅凭 1113 提示用户充值。
- 额度刷新等待 Harness 返回或达到查询超时，超过 10 秒不会被 HTTP 提前截断；查询失败在对应卡片显示。查询后清理进程的错误记入服务日志，不导致整个应用退出。
- 阅读流式回复：主动向上滚动立即暂停自动跟随，后续文本和工具更新保留阅读位置；回到底部或点击「回到最新」才恢复。小幅触控板输入同样有效，终端开合和任务面板变化不能重新抢回滚动。
- 时间线：思考（折叠）、工具卡片（状态、diff、终端输出）、计划清单、权限弹窗、提问卡片；输入 `/` 弹出 Harness 的斜杠命令；可附图片。「回复详情」面板除状态与工具名外还包含完整时间线，打开或关闭面板不改变聊天阅读位置。聊天顶部有结论卡时置顶显示，默认一行（当前目标 + 决策与未完成数量），展开显示当前目标、关键决定与未完成事项，可跳到来源消息；窄屏可读，长内容在卡片内滚动。
- `$` Skill 补全：展示当前会话清单的全部条目，可滚动、按名称或描述关键词搜索，名称前缀优先；支持正文空白后的 token，保留前后文。方向键遍历并让选中项保持可见，Tab / Enter 补全而不发送，Esc 关闭不丢草稿；金额、Markdown 代码和无匹配查询不触发替换。补全不扩展 Skill 的来源或启用范围。
- 通知页：保留主开关与回复完成、需要你批准、出错、需要登录或 Key 的分类开关；关闭主开关时分类暂不可操作，重新开启保留原偏好。移除发送测试通知、发送结果、状态、签名及开发版等诊断展示；仅在浏览器已拒绝通知时显示简单权限设置提示。当前会话在前台时不发送系统提醒，其他会话仍积累未读。
- 任务防休眠：桌面版在「设置 → 通知 → 任务运行」提供独立开关，默认关闭。开启后任意会话仍有 Agent 任务就阻止自动休眠，允许屏幕熄灭；所有任务结束、失败或取消、关闭开关或退出应用后释放。状态由主进程管理，不依赖当前页面；断线释放、重连按完整快照恢复。浏览器版显示不可用。

## 消息阅读

- 打开或刷新会话先显示最近 200 条消息；顶部可「加载更早消息」，按消息序号向前分页，直到完整历史。加载期间仍接收实时消息，保留当前阅读位置；失败保留记录并可重试。重连保留已加载的历史窗口，切换会话后忽略旧请求。
- Markdown 保留标题、列表、引用、链接、GFM 表格和普通代码高亮。仅显式 `mermaid` 代码围栏转为图表，聊天内保持紧凑，可展开源码或点击放大。
- 图表复用当前明暗主题、字体与中性色，静态呈现。正在生成的片段、语法错误或不支持的配置 / 外部资源保留可读源码；后续内容修正后自动恢复，渲染失败可重试。不执行图内链接、回调或动画。
- Mermaid 与 Markdown、ACP 时间线、工具图片共用放大预览。默认适应窗口，可切换原图并滚动查看；Escape、背景或关闭按钮退出，焦点回到原图片，不改变消息阅读位置。含图片的 Markdown 链接保留独立的「打开链接」入口。
- 已打开的预览不会因后续文本到达或明暗主题切换而关闭。相同图表在换主题时保留原图模式与焦点，绘制完成后替换图像；源代码变化时不显示旧内容冒充新图，图片加载失败如实提示。

## 验收条件

- 四种界面语言可保存、刷新后恢复，并同步到同一本机服务的其他窗口；服务端值覆盖启动缓存。快速连续修改最终保存最新草稿，保存失败有明确提示且可重试，失败的语言选择不冒充已生效。切换时输入草稿、名称、路径、模型 ID 和聊天正文保持原值；桌面菜单与通知的应用文案同步。窄屏下较长的翻译不截断主要操作，服务商表单可滚动且保存按钮可达。浏览器验证与真实桌面原生菜单验证分别记录。
- `TUANTUAN_MOCK_HARNESS=1` 下不装任何 CLI 可完成（`bun run e2e` 覆盖）：首次引导选 mock → 一键登录 → 起名后进入草稿会话 → 之后不再出现 → Harness 页一键安装（本地脚本 + mock Registry 的二进制包）与握手 → 建 Agent（Skills 列表）→ 建项目 → 多 Agent 会话：不 @ 时主 Agent 回复、@ 时被 @ 者回复、handoff → 单 Agent 会话中看到斜杠命令、计划、思考、权限 + diff、终端、配置项、用量、取消 → 服务商与用量（Token 统计：mock 每轮报告 usage、模型和累计费用，按 Agent / 模型分组；缓存卡片显示读 / 写与一位小数的缓存命中率，分母为 0 时显示「无数据」；没报告的 Harness 显示「无数据」）。
- 桌面版（Linux AppImage，`bun run desktop:smoke`）：随包 Bun 服务端启动、preload 桥、Codex 从 Registry 安装后握手、Skills 从用户目录发现并在 Agent 页显示、mock 对话、退出时进程全部结束。
- 真实 Harness 在登录后能完成对话；未登录时显示明确的登录提示。
- 经团团 ACP 文件接口访问的工作目录外路径和符号链接逃逸被拒绝；ACP 终端的目录检查只覆盖启动 cwd，不据此声称命令或 Harness 被操作系统沙箱隔离。
- 初始化期间取消后不发 prompt；运行中的取消超时能终止 Harness / ACP 终端进程组，后续请求可重建 / 恢复。安装取消后不遗留安装命令子进程。
- 慢快照返回后运行状态、权限弹窗与提问卡片保留；授权或回答提交失败有提示、可重试，pending 不重复提交，404 可关闭。
- 提问卡片：合法回答能送达 mock Agent；缺必填、越界和未知类型被拒绝且卡片保留；关闭、停止任务、进程退出或离开会话都以 cancel 收尾，pending 不残留；刷新后提问仍在，四种界面语言文案齐全。
- 结论卡：显示最近一条成功的根任务 / 群主跟进笔记，成员笔记不进入；没有新笔记的新一轮保持上一张；点击定位来源消息；无笔记时隐藏；刷新后按消息重新派生。
- 中断的请求可通过「重试此请求」按原文与图片发起新请求并引用原消息；单聊与群聊的 @ / 群主路由和原消息一致，非中断消息不提供该操作。
- 超过两页的聊天记录可连续回看到最早一条，无重复或遗漏；分页、失败重试与实时消息到达不抢走阅读位置，重连后已加载窗口保留，断线期间超出一页的新消息仍能补齐。
- 同群不同 Agent 同时运行，同一 Agent 严格排队；新消息不取消旧任务；取消排队项、活动任务或交接来源，只影响选中任务及依赖后继，独立任务继续。取消超时强制回收不会终止其他会话的同一 Agent。
- 不 @ 的群聊请求可由群主向多个成员分工，一批完成后只触发一次群主跟进；成员失败 / 取消也回报，长结果可读全文。连续补充分工共享 5 次预算，预算耗尽后仍能汇总；不同请求的结果不混入同一结果报告。明确 @ 成员（包括群主）、@所有人 与单 Agent 对话不触发自动汇总。换群主、移除成员、取消祖先及关闭服务后不复活已取消工作。
- 结构化目标、关键决策和未完成事项可沿 A → B → C 交接及多批群主跟进保留；显式清空生效，已接受交接不被后续保存改写，独立请求不串用。失败、取消、输出上限、中断或迟到调用不提交笔记；成功笔记刷新 / 重启后可读，界面可展开且窄窗可用键盘查看尾部。
- 交接说明在 16,000 字符内完整保存并可分页还原，超限或非法笔记不耗预算、不改变已有值；2000 字符摘录省略部分及早于 30 条候选的原文可追读，其他请求的新消息不挤掉本轮来源。消息目录 / 正文分页不重复、不遗漏，跨房间、未来独立请求、生成中及过期任务读取被拒绝。长任务汇总使用可追读摘录并保留完整笔记，不改各 Harness 原生压缩机制。
- 非本机 Host / 浏览器 Origin 的 HTTP 与 WS 请求被拒绝；正常本机 Vite 代理与原生本机客户端可用。
- 流程图与时序图在浅深色主题下可读，普通代码和表格不受影响；错误 / 未完成图表保留源码，修正后恢复；不支持的外部资源语法不能在图表测量阶段发出请求。
- 图表及三类图片均可用键盘和点击打开预览，支持原图 / 适应窗口、关闭与焦点恢复；预览期间流式更新和换主题保持打开状态，窄窗口无页面横向溢出，关闭后保持阅读位置。

## 待验证假设

- 各 Harness 登录后的完整能力（图片、会话恢复、配置项）是否与握手时声明的一致，需要在 Andy 本机实测。
- 多 Agent 会话以「上次发言之后的记录」作为提示是否足够，还是需要摘要。

## 品牌

- 名称：**团团 Tuantuan**，意思是"团聚、圆滚滚"，指一群 Agent 围在一起协作。
- Logo：两个圆形 Bot 依偎在一起（石墨色在前、珊瑚红在后），沿用头像的斜眼睛造型；导航栏里的 Logo 会眨眼，悬停时两个 Bot 互相看一眼，开启"减少动态效果"时静止。
- 资源：`web/public/favicon.svg`（随系统深浅色切换）、`favicon-32.png`、`apple-touch-icon.png`，字标在 `docs/brand/`。
- 仓库：`bosshanz/tuantuan`（原 `agent-hub`，旧地址自动跳转）。
- 兼容：`AGENT_HUB_*` 环境变量、默认数据库文件名和 localStorage 键保持不变。

- 自定义 API（BYOK）：内置的轻量对话 harness（OpenAI Chat / Responses / Anthropic），支持交接；无文件和终端。用户明确要求后加入，对「不做内置 Harness」的决定是一处有意的例外。
- Skills：每个 Agent 一套，SKILL.md 约定，可导入、启停；`/` 命令、`$` Skills 补全。
- Skills 索引不隔离用户 Harness 配置（不设 CLAUDE_CONFIG_DIR/CODEX_HOME）；CC Switch 的 ANTHROPIC_* 与 Codex config.toml model_provider 原样继承。
