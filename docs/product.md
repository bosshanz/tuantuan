# 团团 Tuantuan 产品说明（MVP）

## 用户任务

1. 用本机已安装的编码 Harness（Claude Code / Codex / Grok Build / OpenCode）组合出不同角色的 Agent：Harness、身份文档、MCP 服务器、环境变量、权限策略。
2. 在群聊中 @ Agent 让它们回答（不 @ 时由群的主 Agent 回答，@所有人 时每个都回答）。
3. 私聊时完整看到 Harness 的能力：流式回复、思考、工具调用（diff / 终端）、计划、权限请求、配置项、斜杠命令、图片、会话历史、用量。

## 业务规则（已确认，2026-10-14 Andy 决策）

- 团团不内置模型，也不做模型路由；模型、Key、登录全部由 Harness 管理。新手引导（仅首次启动出现一次）检测 Harness、提示安装与登录、做 ACP 握手。
- Agent 名称唯一（不区分大小写），不能包含空白、`@`、反引号，也不能是 `所有人` / `all` / `everyone`；名称即 @ 的目标。
- 每个 Agent 一个 Harness 进程（按 Agent + 会话工作目录区分），每个会话对应一个 ACP session，重启后恢复（resume / load）。
- 文件读写和终端请求只允许在会话的工作目录内；写入与命令需要用户在权限弹窗中允许（一次 / 总是 / 拒绝），或按 Agent 的权限策略处理。
- 身份文档保存在团团，不写入用户仓库：Claude 用 `_meta.systemPrompt.append`，Grok 用 `_meta.rules`，Codex 用进程环境 `CODEX_CONFIG.developer_instructions`，其他 Harness 附加在会话第一条消息前。
- 群聊：
  1. @ 了具体 Agent → 只有这些成员回复。
  2. 没有 @ → 群的**主 Agent**回复（建群时默认第一个成员，可在详情面板修改）。
  3. `@所有人`（或 `@all`、`@everyone`）→ 每个成员按顺序各回复一次。
  4. 每个会话（群聊或私聊）有自己的工作目录：默认在 `~/Tuantuan/<会话名>` 自动创建（`TUANTUAN_WORKSPACES` 可改），也可选已有文件夹，之后可修改；群内 Agent 共用它；Agent 收到的是它上次发言之后的群聊转述（最多 30 条 / 约 8000 字，保留最新的并注明省略条数，单条超过 2000 字截断）。
  5. Agent 之间只能通过团团注入的 `tuantuan` MCP 服务器上的 `handoff(agent, task)` 交接：只能交给群里的其他成员，不能交给自己；本条消息里已在排队的不重复触发；`@所有人` 这一轮已回复过的不再触发；每条人类消息最多 5 次交接，超出时停止并提示；回复失败或被取消时它发起的交接作废。正文里的 @ 永远不触发。
  6. 新消息打断当前回复链，未执行的触发（含交接）列在系统消息里后丢弃。
- 私聊：每条消息都由该 Agent 回复；新消息排队。私聊不注入 `tuantuan` 工具。
- 登录：Harness 页握手后报告是否已登录；Harness 声明了 agent 类型的登录方式时可一键调用 ACP `authenticate`（由 Harness 自己完成，可能打开浏览器），否则复制终端登录命令；完成后重新检测。
- 切换到 Harness 的历史会话时 `session/load`，回放中团团没有的轮次（按用户消息文本去重）只读显示在顶部。
- 取消：向 Harness 发送 `session/cancel`，保留已生成内容并标记「已取消」。
- 失败如实展示：Harness 未安装、未登录（Authentication required）、进程退出（附 stderr 末尾）都显示在对应消息上。

## 关键状态

消息：`回复中` → `完成` / `失败` / `已取消`；服务重启时未完成的消息变为 `已中断`。
会话：空闲 / Agent 正在回复（可取消）/ N 条排队中。

## 界面

- 视觉：现代、俏皮但克制，和圆滚滚的 Bot 吉祥物相配。中性底色（浅色 `#ffffff` / `#f5f5f3`，深色 `#161618` / `#111113`），石墨色文字与主按钮；品牌色番茄珊瑚红（Logo `#f2553c`，交互 `#e8462b`，深色 `#ff6a4d`）只用于发送、按住说话、选中图标、@ 提及和交接这类关键位置；色彩主要来自 Agent 头像（13 种鲜亮颜色）。字体 Plus Jakarta Sans Variable（自托管拉丁）+ 苹方 / 系统中文黑体，标题与正文同一家族、靠字重区分。表面圆角 10–16px（不做全胶囊），1px 细线 + 轻柔分层阴影，按钮按下有轻微回弹，减少动态效果时关闭。避免：默认靛蓝、满屏渐变、毛玻璃、emoji 图标、卡片网格。界面不写操作说明，解释都放在文档里。
- 动效：切换页面/会话时主区域淡出淡入并轻微位移（支持 View Transitions 的浏览器用它，其他浏览器退回 CSS），弹层、@ 列表、Cmd+K、头像选择器从触发位置缩放淡入，右侧面板滑入滑出（窄屏为底部抽屉），新消息上浮淡入；时长 120/180/220ms，统一缓动 token；关闭时也有退场动画；开启「减少动态效果」时全部关闭。
- 对齐：所有列的标题栏同在一条 56px 线上（导航 Logo、列表标题、主区域标题、详情标题），标题栏不透明并带底部细线，内容在其下方滚动、不重叠；列表、消息列、输入框、详情键值列各自共享左边缘。e2e 用 `getBoundingClientRect` 断言这些对齐。
- 桌面三栏：导航栏（会话 / Agents / Harness / 搜索 / 显示名 / 连接状态）+ 列表 + 主区域，详情面板可展开；≤1180px 时详情变为浮层，手机端列表和主区域分屏切换，详情变为底部抽屉。浅色/深色跟随系统，尊重减少动效设置。
- 会话列表按群聊 / 私聊分组；Cmd/Ctrl+K 打开切换器。
- Agent 头像：13 种手绘 SVG Bot 轮廓 + 13 种颜色（默认按 Agent id 确定性生成，存于 `avatar_shape` / `color`）；在编辑页点击头像打开选择器（方向键切换、Esc 关闭、可重置）。人类头像为描边圆。头像有表情：平静 / 开心 / 思考 / 说话 / 惊讶 / 难过 / 休眠。只有正在进行的回复和成员列表会动（眨眼、呼吸、张望；等首字时思考摇摆，流式输出时说话，开始回复时跳一下，结束时短暂微笑，失败时摇一次）；20px 以下只眨眼，减少动态效果时全部静止，离屏和标签页隐藏时暂停。预览页：`#/dev/avatars`。
- Agent 编辑：顶部 56px 标题栏（小头像 + 名称 + Harness 名称，右侧「私聊」）；分区（基本信息、Harness、权限策略、身份文档、MCP 服务器、环境变量、危险操作）；底部不透明保存条。
- 新手引导（`#/setup`，首次启动自动打开，完成或跳过后不再出现）与 Harness 管理（`#/harness`）：逐个 Harness 显示是否安装、版本、安装命令、登录方式、绝对路径覆盖和「测试」（ACP 握手）。
- 头像表情与真实状态对应：等待首字 = 思考，流式输出 = 说话，失败 = 难过，被取消/中断 = 惊讶，其余 = 平静。
- 聊天：同一发送者 5 分钟内的消息合并；Markdown 与代码高亮；@ 显示为标签并支持自动补全（↑↓ 选择，Enter/Tab 确认；Enter 发送，Shift+Enter 换行）；工具调用默认折叠；每条 Agent 回复下方只有一行弱化的来源信息（「按话题选中」/「接 X 的交接」· 模型 · 是否回退，悬停时加深），点击后在详情面板查看路由、分类器与工具；交接显示为带左侧强调线的卡片；停止按钮与排队数。
- 输入框：在群聊中输入时，底部实时显示这条消息将由谁回复（被 @ 的 Agent / 所有人 / 按话题自动选一位），回复进行中提示「发送会打断当前回复」。
- 会话信息面板（默认收起）：成员与 Harness；工作目录（群聊另有主 Agent）设置；每个 Agent 的 ACP 会话（历史列表、切换、新会话）、配置项与用量。
- 私聊时间线：思考（折叠）、工具卡片（状态、diff、终端输出）、计划清单、权限弹窗；输入 `/` 弹出 Harness 的斜杠命令；可附图片。

## 验收条件

- `TUANTUAN_MOCK_HARNESS=1` 下不装任何 CLI 可完成：首次新手引导握手 → 完成后不再出现 → 建 Agent → 建群 → 不 @ 时主 Agent 回复、@ 时被 @ 者回复 → 私聊中看到斜杠命令、计划、思考、权限 + diff、终端、配置项、用量、取消。（`bun run e2e` 覆盖）
- 真实 Harness 在登录后能完成私聊对话；未登录时显示明确的登录提示。
- 群聊里主 Agent 调用 handoff 后对方接手并显示交接卡片（mock 两种传输都有测试；OpenCode 免费模型实测 HTTP 与 stdio 都通过）。
- 引导页：mock 未登录 → 一键登录 → 已登录（e2e 覆盖）。
- 工作目录外的读写被拒绝。

## 待验证假设

- 各 Harness 登录后的完整能力（图片、会话恢复、配置项）是否与握手时声明的一致，需要在 Andy 本机实测。
- 群聊以「上次发言之后的记录」作为提示是否足够，还是需要摘要。

## 品牌

- 名称：**团团 Tuantuan**，意思是"团聚、圆滚滚"，指一群 Agent 围在一起协作。
- Logo：两个圆形 Bot 依偎在一起（石墨色在前、珊瑚红在后），沿用头像的斜眼睛造型；导航栏里的 Logo 会眨眼，悬停时两个 Bot 互相看一眼，开启"减少动态效果"时静止。
- 资源：`web/public/favicon.svg`（随系统深浅色切换）、`favicon-32.png`、`apple-touch-icon.png`，字标在 `docs/brand/`。
- 仓库：`bosshanz/tuantuan`（原 `agent-hub`，旧地址自动跳转）。
- 兼容：`AGENT_HUB_*` 环境变量、默认数据库文件名和 localStorage 键保持不变。
