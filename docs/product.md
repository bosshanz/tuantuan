# 产品说明（MVP）

## 用户任务

1. 用 Prompt + 工具 + Skills 快速组合出不同角色的 Agent，并选择 Auto 或固定模型。
2. 在群聊中 @ Agent 让它们回答，Agent 之间可以互相 @ 接力。
3. 了解每条回复用了哪个模型、为什么、是否发生回退，以及调用了哪些工具。

## 业务规则（已确认）

- Agent 名称唯一（不区分大小写），不能包含空白、`@`、反引号；名称即 @ 的目标。
- 群聊：只有被 @ 的**房间成员**会回复；没有 @ 时无人回复。私聊：每条消息都由该 Agent 回复。
- Agent 回复中 @ 其他成员会触发对方；@ 自己无效。
- 每条人类消息引发的 Agent 互相 @ 最多 `maxAgentHops` 次（默认 5），超出时停止并在会话中提示未执行的触发。
- 同一会话同时只处理一条人类消息的回复链，后续消息排队；不同会话互不影响。
- 取消：停止当前回复（保留已生成内容，标记「已取消」），并丢弃排队中的消息（会话中提示数量）。
- 失败如实展示：模型全部失败、工具失败、达到工具迭代上限、服务重启中断都会在对应消息上显示原因。

## 关键状态

消息：`回复中` → `完成` / `失败` / `已取消`；服务重启时未完成的消息变为 `已中断`。
会话：空闲 / Agent 正在回复（可取消）/ N 条排队中。

## 界面

- 桌面三栏：导航栏（会话 / Agents / 机器人 / 搜索 / 显示名 / 连接状态）+ 列表 + 主区域，详情面板可展开；≤1180px 时详情变为浮层，手机端列表和主区域分屏切换，详情变为底部抽屉。浅色/深色跟随系统，尊重减少动效设置。
- 会话列表按群聊 / 私聊 / 桌面机器人分组；Cmd/Ctrl+K 打开切换器。
- Agent 编辑：分区卡片（基本信息、系统 Prompt、模型、工具、Skills、危险操作）、可搜索的勾选列表、底部保存条（显示未保存修改）。
- 聊天：同一发送者 5 分钟内的消息合并；Markdown 与代码高亮；@ 显示为标签并支持自动补全（↑↓ 选择，Enter/Tab 确认；Enter 发送，Shift+Enter 换行）；工具调用和路由默认折叠，点击路由标签在详情面板查看；Agent 互相 @ 的跳数标记；停止按钮与排队数。
- 桌面机器人（`#/robot`）：选择绑定的 Agent，动画脸部显示 待机/聆听/思考/说话/开心/难过或出错/惊讶；按住说话或免提（Web Speech），zh-CN 朗读，文字输入兜底；可以打断（barge-in）；Agent 通过 `robot_express` / `robot_action` 控制表情和动作（点头、摇头、歪头、挥手、环顾、跳舞）。对话保存为聊天列表中的「桌面机器人 · Agent」会话。协议见 [device-protocol.md](device-protocol.md)。

## 验收条件

- 不配置任何 Key，`bun dev` 后可完成：建 Agent → 建群 → @A → A @B → B 回复，且能看到路由信息。
- A、B 互相 @ 时在第 `maxAgentHops` 次后停止并出现提示。
- 勾选工具后，工具调用及失败在 UI 中可见。
- 取消后正在回复的消息显示「已取消」，排队消息不再触发。

## 待验证假设

- 真实模型下的分类质量与路由表默认值是否合适，需要用实际任务观察路由记录后调整。
- 串行执行多个被 @ 的 Agent 是否足够快。
