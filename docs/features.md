# 功能一览

- **桌面版**（macOS / Windows / Linux，Electron）或浏览器 + 本机服务。
- **Harness**：自动发现你自己装的版本；没有时一键装到团团自己的目录（ACP Registry 或明确标注来源的补充条目，固定版本、不用 sudo，二进制按提供的校验和验证）；握手测试与登录引导。常用入口包括官方 DeepSeek CLI 预发布版，沿用本机 `dsh` 或按需安装，支持 Key 配置；握手不代表 Key 有效，详见 [Harness](harness.md)。
- **会话**：按项目分组；单 Agent 直接对话，多 Agent 由群主负责分工、跟进和汇总，明确 @ 成员保持直达；支持 @所有人、`handoff` 交接和引用回复。新消息默认排队；排队消息可「立即发送」——原地提升为引导、打断同车道选定执行链后优先执行，也可「编辑消息」撤回尚未开始的排队消息并拉回输入框修改。侧栏随回复完成更新预览，断线重连后补齐。
- **消息阅读**：Markdown 支持 Mermaid 代码围栏（跟随明暗主题，可查看源码）；图表、Markdown、ACP 与工具图片可点击放大，支持缩放、拖动、适应窗口 / 原图，按 Esc 关闭。
- **历史回看**：会话先显示最近 200 条消息，顶部可继续加载更早记录；保留阅读位置，失败可重试，重连保留已加载记录。
- **文件工作台**：会话右侧并排停靠可调宽工作台，统一浏览项目目录树（支持文件名搜索与虚拟滚动）、Git 变更、Agent 改动和聊天附件；右侧直接集成图片、Markdown、语法高亮代码、隔离静态 HTML 与 diff 预览，并支持原件下载与返回来源消息。Agent 正文里的本地文件链接点击后在工作台打开对应文件，工作区外路径由桌面端交给系统文件管理器。
- **协作改动核对**：在文件工作台按路径查看 Agent 报告的历史编辑、重叠标记与来源消息，或只读核对会话目录范围内的 Git 工作区状态；目录树直接标记改动，Git 改动不归因给当前会话或某个 Agent。
- **聊天内容搜索**：侧栏搜索或 ⌘K / Ctrl+K 搜索全部已保存的聊天正文，同时保留会话 / Agent 快速切换；聊天顶部或 ⌘F / Ctrl+F 只搜当前会话。结果显示会话、作者、时间和匹配片段，点击定位原消息，可返回刚才的阅读位置。
- **需要我处理**：侧栏顶部图标打开待办，集中展示等待批准、等待回答、需要登录 / Key、失败与中断；点击回到原会话处理。授权与提问按实际状态自动移除；失败需要明确点击「从待办移除」，刷新或重启后仍保留处理结果。
- **项目终端**：会话右上角打开内嵌交互式终端（macOS / Linux），默认进入项目目录；用标签页多开独立 shell，支持新增、切换、单独结束、Ctrl+C、调整高度和平滑展开 / 收起。收起保留全部终端，刷新后重连；支持减少动态效果。
- **服务商与用量**：给 Claude Code / OpenCode / Pi / Codex / 自定义 API 配置服务商（Key 只在服务端、打码显示），只读导入 CC Switch，查看本机用量和余额。
- **模型能力与思考**：models.dev 离线目录与 Pi AI 协议兼容规则支持四个编码 Harness；可主动同步、为模型别名关联能力来源。只显示实际支持的档位，保留会话选择，未知模型不猜测能力。
- **Skills**：自动发现 `~/.agents`、`~/.claude`、`~/.codex`、插件和项目里的 Skills，按 Agent 勾选；可从链接或文件夹导入。
- **界面语言**：简体中文、繁体中文、英语、日语，默认简体中文；在「设置 → 个人资料 → 界面语言」选择后自动保存，保存成功即生效，同一本机服务的其他窗口同步。桌面菜单及系统通知的应用文案跟随语言，聊天内容、Agent 正文和模型回复语言不变。
- **通知**：「通知」页提供主开关与回复完成、需要批准、出错、需要登录或 Key 的分类开关；测试发送与签名诊断已移除。看着当前会话时不提醒，其他会话保留未读计数。
- 模型、登录由 Harness 自己管理；团团从不改 `~/.claude` / `~/.codex`。
- 不装任何 CLI 也能体验：`TUANTUAN_MOCK_HARNESS=1` 启用内置 mock ACP agent。
