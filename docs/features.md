# 功能一览

- **桌面版**（macOS / Windows / Linux，Electron）或浏览器 + 本机服务。
- **Harness**：自动发现你自己装的版本；没有时一键装到团团自己的目录（官方 ACP Registry，固定版本、校验和、不用 sudo）；握手测试与登录引导。
- **会话**：按项目分组；单 Agent 直接对话，多 Agent 由群主负责分工、跟进和汇总，明确 @ 成员保持直达；支持 @所有人、`handoff` 交接和引用回复。侧栏随回复完成更新预览，断线重连后补齐。
- **消息阅读**：Markdown 支持 Mermaid 代码围栏（跟随明暗主题，可查看源码）；图表、Markdown、ACP 与工具图片可点击放大，切换适应窗口 / 原图，按 Esc 关闭。
- **历史回看**：会话先显示最近 200 条消息，顶部可继续加载更早记录；保留阅读位置，失败可重试，重连保留已加载记录。
- **项目终端**：会话右上角打开内嵌交互式终端（macOS / Linux），默认进入项目目录；用标签页多开独立 shell，支持新增、切换、单独结束、Ctrl+C、调整高度和平滑展开 / 收起。收起保留全部终端，刷新后重连；支持减少动态效果。
- **服务商与用量**：给 Claude Code / OpenCode / Pi / Codex / 自定义 API 配置服务商（Key 只在服务端、打码显示），只读导入 CC Switch，查看本机用量和余额。
- **模型能力与思考**：models.dev 离线目录与 Pi AI 协议兼容规则支持四个编码 Harness；可主动同步、为模型别名关联能力来源。只显示实际支持的档位，保留会话选择，未知模型不猜测能力。
- **Skills**：自动发现 `~/.agents`、`~/.claude`、`~/.codex`、插件和项目里的 Skills，按 Agent 勾选；可从链接或文件夹导入。
- **界面语言**：简体中文、繁体中文、英语、日语，默认简体中文；在「设置 → 个人资料 → 界面语言」选择后自动保存，保存成功即生效，同一本机服务的其他窗口同步。桌面菜单及系统通知的应用文案跟随语言，聊天内容、Agent 正文和模型回复语言不变。
- **通知**：「通知」页提供主开关与回复完成、需要批准、出错、需要登录或 Key 的分类开关；测试发送与签名诊断已移除。看着当前会话时不提醒，其他会话保留未读计数。
- 模型、登录由 Harness 自己管理；团团从不改 `~/.claude` / `~/.codex`。
- 不装任何 CLI 也能体验：`TUANTUAN_MOCK_HARNESS=1` 启用内置 mock ACP agent。
