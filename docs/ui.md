# 界面与视觉

界面语言、截图、视觉风格与 Agent 头像。

## 界面语言

打开侧栏底部「设置」，进入「个人资料」，在「界面语言」选择简体中文、繁体中文、英语或日语。默认简体中文；选择后自动保存，保存成功后切换当前界面，同一本机服务的其他窗口也会同步。保存失败时保留草稿并显示「重试」。桌面菜单和系统通知的应用文案使用同一语言。

语言设置只改变应用文案，不改写聊天、Agent 正文、名称、路径或模型 ID；第三方 Harness 的未知文案与错误保留原文，也不会因此要求模型改用另一种语言回答。状态、按钮、帮助、输入提示及无障碍标签随界面语言更新。

## 模型能力与思考选择

服务商页显示本机目录来源、更新时间及同步入口；搜索只查本地目录，主动点击「同步模型能力」才联网更新。服务商编辑表单的「模型能力来源」默认折叠，展开后可分别关联主模型与快速模型，留空自动识别。

Agent 默认设置和输入框旁的思考选项以 Harness 实际返回为准。「团团推荐」随模型可用能力选择，不覆盖明确保存的设置；切回兼容模型时恢复之前的选择。仅开关能力的 Pi 模型显示「开启」，Claude Code 没有原生关闭选项时不增加按钮。具体边界见 [服务商](providers.md#模型能力目录与思考等级)。

## 界面

聊天主界面围绕用户需要知道的消息组织。精简模式保留各 Agent 的正文与图片，被真实思考或工具记录隔开的正文阶段各自使用主题浅底独立气泡；连续文字、普通换行与相邻图片保留在同一气泡，只有过程没有正文时不生成空气泡。流式追加更新当前气泡，下一段正文出现时才新增气泡，以轻量入场提示变化；减少动态效果时直接显示。同组名字与头像只出现一次，名字与气泡内文字对齐，头像靠上，不增设固定阶段标签，也不把后台工具调用转换成虚构进度。每个气泡有独立的复制与群聊引用入口，只操作当前这段正文；点击消息内或输入框里的引用可定位对应气泡，只有该段正文与图片短暂高亮，完整视图中也保留同一范围。查看原文后可点「返回刚才位置」恢复跳转前的阅读位置，连续查看引用保留最初的返回点；桌面悬停或聚焦时只显示当前气泡的操作栏，窄屏放在各自气泡下方。查看详情和消息 ID 仍对应原始回复。工具、思考、计划、交接记录和任务笔记在「查看详情」中追溯。失败、需要回答的问题和停止操作继续可见。结论与输入框上方的 Agent 回复状态共用一栏：运行中保留状态与结论入口，空闲时显示目标摘要；点击向上浮出非模态详情，消息和输入框保持原位，Escape 或点击外部关闭。来源定位只在目标正文短暂显示中性浅底后淡出，无警示描边。提问默认收成输入框上方的摘要，展开后就地填写，不强制弹窗；少量选项显示为单选行，长表单内部滚动，操作区保持可见。收起保留答案，Tab 可以离开卡片。

表面使用中性色、清楚的字阶和间距，避免玻璃背景与卡片嵌套。完整视图和详情中的笔记、会话内提问以高度过渡开合；结论浮层使用实底、细边线与轻阴影，以轻微位移和透明度进入、退出，和任务列表互斥，长内容内部滚动。动效可连续反向；减少动态效果时直接切换，来源定位使用静态短暂浅底提示。

「精简视图」位于右侧会话信息的「详情」中，对本机所有会话生效。切换时仅消息区短暂淡入，保留正在阅读的消息，快速反向时恢复原位置。

- 现代简洁风格：干净的中性底色（浅色近白 / 深色石墨），品牌色是 Logo 里的番茄珊瑚红，只用在关键动作和状态上；Agent 头像用鲜亮的彩色区分。字体为 Plus Jakarta Sans（已自托管）+ 苹方，浅色/深色跟随系统。设置开关以当前主题强调色表示开启，关闭和禁用使用中性灰，滑块在深浅主题下均保持清晰。
- Agent 头像是 SVG Bot（11 种可选轮廓 × 13 种颜色，含小猫、小狗、兔子、熊猫、山羊、牛），默认按 Agent id 生成，在编辑页点击头像修改。已保存的旧造型仍可显示和保存。头像会根据状态变表情（思考、说话、难过、惊讶、休眠），开启「减少动态效果」时静止。预览全部表情：`/#/dev/avatars`。
